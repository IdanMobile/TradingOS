Sources & sending your own signal

Fear & Greed Index, CoinGecko, and Binance 24h momentum are free, keyless, and always on. Manage every source — including paid/deferred ones — in Settings → Integration → Signals.

To send your own (e.g. a real TradingView alert), POST JSON to /api/v1/signals/ingest with secret (must match TIOS_SIGNALS_WEBHOOK_SECRET), source, symbol, action (BUY/SELL/HOLD), optional rationale:

curl -X POST http://127.0.0.1:8765/api/v1/signals/ingest \
  -H "Content-Type: application/json" \
  -d '{"secret":"...","source":"TradingView Webhook","symbol":"BTCUSDT","action":"BUY","rationale":"Volume breakout above 20D high"}'
